The directory `conf/` holds four service configuration files and `POLICY.txt`, which lists the rules every configuration must follow. Several values break the rules. Fix the configuration files so that every rule holds, changing only the values that need to change and keeping comments and the order of lines.

Then write `CHANGES.txt` in the current directory with one line per value you changed, written as `<file>:<key>` (for example `app.ini:port`), sorted in byte order and each listed once.
